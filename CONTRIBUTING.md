# Contribuir

Abra uma issue sem dados de clientes para discutir mudanças maiores. Para corrigir código: crie uma branch, mantenha a alteração pequena, acrescente testes de comportamento e execute os testes de backend/frontend documentados no README. Não adicione áudio real, `.env`, certificados, dumps, backups ou chaves de API. Use fixtures sintéticas; chamadas pagas à IA não fazem parte da suíte padrão.

Questões de segurança devem seguir `SECURITY.md`, nunca uma issue pública. O mantenedor revisa compatibilidade de API, permissões, migrações, retenção e documentação antes de aceitar mudanças.
